An obligation has to be about the value the test checks, or about what the changed function
returns, raises or modifies when code the golden patch does not change computes that value from
it. Such an obligation states the behavior only with a frame -- the function changes nothing
else that code reads -- and only if the model's types tell apart every two effects that code
treats differently. A clause about a proxy -- a flag, an emptied cache, a local the function
computes on the way -- whose link to what the test checks lives in `correspondence.md` or in
`conformance.py` does not state the behavior.
