What a witness test cites asks for a behaviour -- a value returned, an exception raised, or an
effect on state -- or for none. A sentence of the statement asks only for what it states. A
sentence naming a quality goal -- performance or overhead, compatibility, robustness, handling
something gracefully, clean or maintainable code -- asks for no behaviour beyond what it states.
A test id asks for what that test asserts, on its inputs or on others of the same kind.
